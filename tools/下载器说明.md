# PclBridge 下载器（安装 / 卸载说明）

## 统一安装位置

所有脚本只认一个位置（不再复制到 %LOCALAPPDATA%）：

    <扩展目录>\pcl\PclBridge.exe

配置文件（安装脚本自动生成）：

    <扩展目录>\pcl\bridge.json
    { "exe": "...\pcl\PclBridge.exe", "port": 6806, "threads": 8, "extId": "..." }

## 安装

双击 \tools\安装下载器.bat，或命令行：

    powershell -NoProfile -ExecutionPolicy Bypass -File tools\install-host.ps1

可选参数：

    -ExtId <32位ID>   不传则自动扫描 Edge/Chrome 配置，失败用内置 ID
    -Threads 16      线程数
    -Port 6806       端口
    -NoStart         只写注册/清单，不启动
    -Force           有下载任务在跑时也强制安装（默认会中止）

装完**完全关闭 Edge**（任务管理器确认无 msedge）再打开。

## 开机守护（可选）

    powershell -File tools\install-watch.ps1

写入 HKCU\...\Run\PclBridgeWatch → 运行 tools\watch-guard.ps1
守护脚本从 bridge.json 读取端口和 exe 路径，浏览器关闭 20 秒且无下载任务时自动退出。

## 卸载

双击 \tools\卸载下载器.bat，或：

    powershell -File tools\uninstall-host.ps1            # 保留文件
    powershell -File tools\uninstall-host.ps1 -KeepFiles # 同左

会清理：开机守护项、watch.vbs、三个原生宿主注册表键、com.pclbridge.bridge.json。
PclBridge.exe 与 bridge.json 保留，便于回滚。

## 常见问题

- 扩展提示“下载桥接未连接”：先确认 Edge 完全关闭再开；仍不行重跑安装脚本。
- 端口被占用：换 -Port 后同步在扩展设置里改“接口地址”为 http://127.0.0.1:<端口>。
- 安装提示“有 N 个下载任务在跑”：等任务完成，或加 -Force。
